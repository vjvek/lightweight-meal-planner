Create a Meal

Create a meal or edit an existing one using the dropdown list below.

When creating a new meal, only the name is required. Everything else is optional. The meal creator provides you with the following features to help you get the most out of your meals:

  • Adding quantities to your ingredients allows you to dynamically recalculate them based on your chosen serving size
  • A sorting button to reorder ingredients
  • Create dividers to split up your ingredients into sections

Helpful tips:

  • A meal can be saved with or without ingredients
  • An ingredient can be saved with or without quantities
  • If you're adding the quantity to an ingredient, you must include the unit otherwise it won't save
